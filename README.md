## ◆ About LET'S COOK

**LET'S COOK** is a student-driven community focused on technology, innovation, collaborative learning, and building real-world solutions. We bring together students, developers, designers, innovators, and technology enthusiasts who want to **learn by building**.

We believe in experimentation, collaboration, practical implementation, and sharing what we learn along the way. Our core team operates under the identity **THE FOUNDRY**: the people who build, organize, manage, and execute the community's initiatives.

> **Tagline:** *Where ideas turn into projects, developers turn into collaborators, and learning turns into building.*

<img src="./assets/divider.svg" alt="" width="100%">

## ◆ Vision

We want to create an environment where students **don't just consume technology; they build it.**

Over time, we aim to:

- Build a strong developer ecosystem.
- Encourage open-source contributions.
- Connect students with real-world technology.
- Promote collaborative development and experimentation.
- Help beginners grow into practical developers.
- Create opportunities to work on meaningful projects with real-world impact.
- Connect developers from different backgrounds and institutions.

## ◆ How to Contribute

New to GitHub? Follow the path below from top to bottom. Every step is explained in plain language.

<div align="center">

<img src="./assets/workflow.svg" alt="Contribution workflow in 8 steps: discover a project, fork the repository, clone it, create a branch, make changes, submit a pull request, go through code review, and get merged." width="640">

</div>

<details open>
<summary><b>The 12-step workflow</b></summary>
<br>

1. **Explore** our [repositories](https://github.com/ORG_SLUG?type=source).
2. **Read** the project's `README.md`.
3. **Check** `CONTRIBUTING.md` for project-specific rules.
4. **Find an issue** to work on, or open one to propose your idea.
5. **Fork** the repository.
6. **Clone** your fork.
7. **Create a feature branch.**
8. **Make your changes.**
9. **Test** your implementation.
10. **Submit a pull request.**
11. **Respond** to review feedback.
12. **Get merged**, and celebrate.

</details>

<details>
<summary><b>Command-line quick start</b></summary>
<br>

```bash
# 1. Fork the repository on GitHub, then clone YOUR fork
git clone https://github.com/<your-username>/<repository>.git
cd <repository>

# 2. Add the original repository as "upstream"
git remote add upstream https://github.com/ORG_SLUG/<repository>.git

# 3. Create a feature branch
git checkout -b feature/short-description

# 4. Make your changes, then commit with a meaningful message
git add .
git commit -m "feat: add short description of the change"

# 5. Push the branch and open a pull request on GitHub
git push origin feature/short-description
```

To stay in sync with the main project:

```bash
git fetch upstream
git rebase upstream/main
```

</details>

## ◆ Community Guidelines

We want LET'S COOK to be a place where people feel safe asking questions and sharing work.

- **Respect** all contributors.
- **Encourage** constructive criticism.
- **Avoid** discrimination and harassment of any kind.
- **Maintain** professional communication.
- **Respect** intellectual property and **give proper credit**.
- **Follow** repository-specific contribution guidelines.
- **Keep** discussions constructive.
- **Help beginners** learn.

> Individual repositories may have their own `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`. Where they exist, those rules apply in addition to the guidelines above.
